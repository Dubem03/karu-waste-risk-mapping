# My GeoDev Lab Africa project

Which communities in Karu Local Government Area, Nasarawa State, are potentially exposed to environmental risks associated with waste disposal sites?

This project uses geospatial and environmental datasets, including waste disposal site locations, settlement data, population data, rivers and waterways, elevation, slope, land use/land cover, rainfall, geological data, and soil information to assess potential environmental risks associated with waste disposal sites.

Built over twelve months with GeoDev Lab Africa, Cohort One.
