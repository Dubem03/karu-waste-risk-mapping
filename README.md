# Karu Waste Disposal Environmental Risk Mapping

## Project Overview

This project uses Geographic Information Systems (GIS) to assess potential environmental risks associated with waste disposal sites and nearby communities in Karu Local Government Area, Nasarawa State, Nigeria.

## Main Research Question

Which communities in Karu LGA are potentially exposed to environmental risks associated with waste disposal sites?

## Key Datasets

**Key Dataset	Source**

Waste disposal site locations	Karu waste management survey / field data
Karu LGA boundary	GRID3 Data Hub
Settlement locations	GRID3 Data Hub
Population data	WorldPop
Rivers and waterways	OpenStreetMap
Digital Elevation Model (DEM)	OpenTopography / Copernicus DEM
Slope	Derived from DEM in QGIS
Land use/land cover	ESA WorldCover
Rainfall	CHIRPS
Geological data	Nigeria Geological Survey Agency (NGSA)
Soil data	ISRIC / SoilGrids

## Project Goal

The project aims to use GIS spatial analysis to examine the relationship between waste disposal sites, communities and environmental factors, and to produce a potential environmental risk map for Karu LGA.

## Expected Output

The final output will be a GIS-based environmental risk assessment and map identifying areas of potential environmental exposure associated with waste disposal sites.

The project may later be developed into an interactive web GIS application.
